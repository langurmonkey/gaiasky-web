# Release Notes


This release adds billboard-based galaxies and nebulae, a passive update notifier, download speed and remaining-time information in the download manager, and lets datasets require a minimum Gaia Sky version. It also moves the textures of the base data pack, so the base data needs to be updated.

## Features

### Galaxies & nebulae
- Add support for nebulae, rendered as billboards. New `nebulae` render type, with its own icon in every skin, and translations for the six bundled languages.
- Add billboard galaxies: new `Billboard` and `BillboardGalaxy` scene graph nodes, and a new `IGalaxyFocus` interface for focus, so that galaxies in the nearby-galaxies catalog are drawn as camera-facing textures instead of meshes.
- Rework the nearby-galaxies loader and the model cache for the new billboard representation. The catalog gains an alias column, and the distance is no longer converted to internal units on load.
- Move the alternate name (`altname`) from the model component to `CelestialBody`, so that all bodies and billboards can have one.
- Add a script to convert Celestia object definitions, with distance in light years and radius in arcseconds, to the parsec-based size and distance used by the descriptors.

### Datasets
- Datasets can declare the minimum Gaia Sky version they require (`mingsversion`). Those requiring a newer version than the running one are not shown in the download manager.
- Add the Large and Small Magellanic Clouds (LMC and SMC) to the data descriptor.
- Bump the internal source configuration version.

### Download manager
- Show the download speed in MB/s, averaged over one-second intervals, together with the downloaded and total size in MB in the download manager.
- Report progress in megabytes from the downloader, instead of only the percentage.

### Update notifier
- Add a passive update notifier, which checks for new versions in the background every few days and, when it finds one, shows a popup linking to the download page. Fixes [#321](https://codeberg.org/gaiasky/gaiasky/issues/321).

### Data loading
- Load `autoload-*.json` files found in the data directory automatically, in addition to the files given to the JSON loader, so a dataset can add objects without editing the main descriptor.
- The JSON loader no longer requires an `objects` element in a descriptor, which allows catalogs and other top-level entries to live in their own files.

## Bug Fixes
- Fix a null pointer exception when unloading stars. Fixes [#322](https://codeberg.org/gaiasky/gaiasky/issues/322).
- Fix a leftover information message: catalogs report the number of objects they loaded, not the number of stars.

## Code refactoring
- Move the regular textures of the base data pack to `tex/base`. The base data pack must be updated, or models will not find their textures.
- Clean up the logging situation: drop the `LogWriter` and the custom `Logger` wrapper, and consolidate on the standard logger, fixing the console logger along the way.

## Build system
- Update to libGDX 1.9.9.
- Update the build scripts to install4j 7.0.8.
- Remove the RPM dependencies from the package, as they depend on the distribution.
- Update the data descriptor with the new DR2 verylarge catalog.

## Documentation
- Update the RPM install command. Fixes [#317](https://codeberg.org/gaiasky/gaiasky/issues/317).
